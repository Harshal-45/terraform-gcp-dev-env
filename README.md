# Terraform GCP Practice

This repository contains Terraform configurations for deploying and managing infrastructure on Google Cloud Platform (GCP). It serves as a hands-on practice project to understand and implement Infrastructure as Code (IaC) using Terraform.

## Project Structure

The project is organized in the following way:

```
TERRAFORM-GCP-PRACTICE/
├── environments/            # Environment-specific configurations
│   └── dev/                 # Development environment configurations
│       ├── main.tf          # Main Terraform configuration file
│       ├── provider.tf      # Provider configurations (GCP)
│       ├── terraform.tfvars # Variable definitions specific to the environment
│       ├── variables.tf     # Variable declarations
├── modules/                 # Reusable Terraform modules
│   └── gcs_bucket/          # GCS Bucket module
│       ├── main.tf          # Module-specific configurations
│       ├── outputs.tf       # Outputs for the module
│       └── variables.tf     # Variables for the module
├── .gitlab-ci.yml           # GitLab CI/CD pipeline configuration
├── output.txt               # Output file generated by Terraform
└── README.md                # Project documentation
```

## Prerequisites

Before running the project, ensure the following:

- [Terraform](https://www.terraform.io/downloads.html) installed (version 1.0 or higher)
- A Google Cloud Platform account
- [Google Cloud SDK](https://cloud.google.com/sdk/docs/install) installed and configured
- A GCP project with billing enabled
- A service account with necessary IAM roles and a generated JSON key file

## Getting Started

### 1. Clone the repository:

```bash
git clone https://gitlab.com/terraform-practice6232617/terraform-gcp-practice.git
cd terraform-gcp-practice
```

### 2. Set up environment variables:

Make sure to set the following environment variables:

```bash
export GOOGLE_CLOUD_KEYFILE_JSON="/path/to/your/service-account-key.json"
export GOOGLE_PROJECT="your-gcp-project-id"
export GOOGLE_REGION="your-gcp-region"
export GOOGLE_ZONE="your-gcp-zone"
```

### 3. Navigate to the environment directory:

```bash
cd environments/dev
```

### 4. Initialize Terraform:

```bash
terraform init
```

### 5. Review the execution plan:

```bash
terraform plan
```

### 6. Apply the configuration:

```bash
terraform apply
```

Confirm the action when prompted.

## Cleanup

To destroy the resources created by Terraform:

```bash
terraform destroy
```

Confirm the action when prompted.

## Modules Overview

### `gcs_bucket` Module

This module manages the creation and configuration of Google Cloud Storage (GCS) buckets.

- **main.tf:** The configuration for the GCS bucket.
- **outputs.tf:** The outputs for the GCS bucket, such as bucket name.
- **variables.tf:** The input variables for the module.

## Best Practices

- **State Management:** Use remote backends like Google Cloud Storage with state locking to manage Terraform state files securely.
- **Modular Design:** Organize resources into modules to promote reusability and maintainability.
- **Environment Separation:** Maintain separate configurations for different environments (e.g., dev, prod) to isolate resources and settings.
- **Version Control:** Pin Terraform provider versions to avoid unexpected changes.
- **Documentation:** Document modules and configurations for clarity and onboarding.
